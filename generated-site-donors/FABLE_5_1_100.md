## Required workflow for subsequent generated-site batches

1. Index **every** HTML file before selection.
2. Extract code-level evidence: functions, APIs, numerical kernels, equations, buffers, integrators and spatial data structures.
3. Classify the **actual primitive**, never the site title or prompt.
4. Mark physical/chemical fidelity separately from visual usefulness.
5. Cluster duplicate primitives within the batch and against earlier model batches.
6. Promote only independently verified candidates into SHADED production donors.
7. Preserve provenance and licensing status; unlicensed generated source is reference-only by default.
