## Most SHADED-relevant takeaways

- **085 is the important sand correction:** unlike the visually named sand demos seen earlier, it actually updates a discrete material grid with downward and diagonal granular motion.
- **082 turns the earlier rope/tentacle constraint family into a surface:** a 2D Verlet cloth with pinning, wind, strain visualization and interactive constraint severing.
- **088 is a rendering donor, not a terrain generator:** the useful part is the front-to-back heightfield column renderer with distance-adaptive stepping.
- **089 is useful precisely because it is CPU-side:** it is a compact black-box reference for SDF sphere tracing, normal estimation and lighting that can be compared against WebGL/WebGPU implementations.
- **083 is a real field update but not full N-body simulation:** particles respond to fixed inverse-square wells; the wells do not mutually integrate.
- **059 is a clean field primitive:** multiple radial sinusoidal sources are superposed over a 2D sampled domain. It is mathematically meaningful without pretending to be a complete water solver.
- **081 must remain downgraded:** the file name says fluid simulation, but the implementation is particle advection through a handcrafted trigonometric flow field.

## Verification policy

1. Generated page title/prompt is metadata, never evidence.
2. Extract the computational kernel and state its actual contract.
3. Mark visual approximations and synthetic data explicitly.
4. Deduplicate by primitive family, not by page theme.
5. Validate equations/units/invariants independently before promotion into a SHADED donor.
6. For regressions or ports, build a reproducible black-box/acceptance test that fails before the fix and passes after it; the generated implementation must not be its own golden oracle.
