## Important failures / false friends
### `065-terrain-fly` — terrain math is effectively dead
The file computes heightfield-like values (`wY`, projected `px/py`) in a nested loop and then does nothing with them. The visible render is a separate circular point pattern. Treat it as a **broken terrain renderer**, not a terrain-flight donor.

### `070-glass-prism` — no refraction physics
Outgoing ray angles are produced by adding an authored `refract/100` angle offset. There is no Snell law, refractive index, wavelength dispersion or interface normal calculation.

### `082-caustic` — no caustics
The page draws straight colored rays toward a horizontal line; it computes neither reflection/refraction nor a focused intensity field.

### `069-wave-diffusion` — no diffusion
It is a stack of prescribed sine curves with modulation. There is no Laplacian, diffusion update or conserved transported quantity.

### `057-equalizer` and `081-sonogram` — synthetic signal displays
Both generate sine/random values locally; neither analyzes real audio. `081` also emits random telemetry values.

### `031-solar-visualizer` — prescribed ellipses, not orbital mechanics
Planets move on authored ellipses with fixed angular speeds. Eccentricity changes the drawn ellipse only; no Kepler equation, gravity or N-body integration is used.

### `085-aperiodic` — not an aperiodic tiling solver
The code places rotated rhombi on a regular grid. There are no Penrose matching rules, substitution system or proof of nonperiodicity.

### `036-noise-terrain` — not coherent terrain noise
The generated profile is assembled from independent hash samples rather than a proper coherent interpolation/fBm field; the declared `noise()` helper is unused.

## Most SHADED-relevant takeaways
1. **042 is the only true standout.** It gives a compact, independent chaotic-system reference that can serve as a black-box integration test across CPU/WebGL/WebGPU implementations.
2. **038 and 053 are small but useful infrastructure primitives.** Isometric projection and axial hex coordinates are the kind of boring spatial math that becomes valuable in editors, debug modes and alternate world representations.
3. **GLM 5.2's visual naming is particularly unreliable.** `terrain-fly`, `glass-prism`, `caustic`, `wave-diffusion`, `sonogram`, and `solar-visualizer` all overstate the actual computation.
4. **The collection is mostly presentation-first.** Compared with Fable/Qwen/DeepSeek-v4-100, GLM 5.2 contributes fewer simulation kernels and more lightweight geometry/interaction patterns.
5. **The overlap implementations are still useful as independent references** only when the algorithm itself is sound; they must never become the golden oracle for SHADED.

## Verification policy
1. Generated page title/prompt is metadata, never evidence.
2. Extract the computational kernel and state its actual contract.
3. Inspect whether computed state is actually consumed by rendering/output; dead math does not count.
4. Mark authored approximations, synthetic metrics and false physical labels explicitly.
5. Deduplicate by primitive family, not by page theme.
6. Validate equations/units/invariants independently before promotion into SHADED.
7. For ports/regressions, use independent black-box scenes/metrics; never use the generated implementation as its own golden oracle.
